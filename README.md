# Bishwajeet Oraon - Personal Portfolio Website

A modern, responsive, and performance-optimized personal portfolio website built with pure semantic **HTML5**, **CSS3**, and **Vanilla JavaScript** (no external framework dependencies required).

---

## 🌟 Highlights & Features

- **Rich Modern Aesthetics**: Glassmorphic UI panels (`backdrop-filter: blur`), subtle ambient glow orbs, and harmonious color tokens.
- **Dark / Light Mode**: Seamless theme switching with system detection and `localStorage` persistence.
- **Dynamic Hero Section**: Interactive typewriter effect rotating through key engineering domains, glowing avatar hologram card, and quick metrics overview.
- **About Me Section**: Comprehensive background story, academic focus in Computer Science Engineering, and core values.
- **Interactive Skills Showcase**: Categorized skill matrix (Languages, Core CS, Web & Backend, AI/ML & NLP, Deployment & AI-Assisted Tools) with interactive filter tabs.
- **Featured Projects**:
  1. **Taste of Heaven** – Full-Stack Restaurant Web Platform (Node.js, Express, Supabase, PostgreSQL, JWT, Vercel)
  2. **Sentiment Analysis** – Machine Learning & NLP System (~99.58% CV Macro F1-Score, Scikit-learn, TF-IDF, Streamlit)
  3. **Heart Failure 30-Day Readmission Prediction** – Clinical Machine Learning & Analytics (Logistic Regression, KNN, Decision Trees, ROC-AUC)
- **Interactive Contact Section**:
  - One-click copy for email (`bishwajeetoraon42@gmail.com`) with toast notification.
  - Direct LinkedIn connection link.
  - Interactive contact form with real-time field validation and direct `mailto:` integration.
- **Fully Responsive**: Flawless experience across mobile devices, tablets, and high-resolution desktop screens.
- **SEO & Accessibility Ready**: Semantic HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), ARIA attributes, and accessible tap targets.

## 🚀 How to Run Locally

You can open and view the website in any modern web browser:

### Option 1: Direct File Opening
Double-click `index.html` or right-click and choose **Open with > Chrome / Edge / Firefox**.

### Option 2: Using VS Code Live Server
1. Open the project folder in VS Code.
2. Install the **Live Server** extension if not already installed.
3. Click **"Go Live"** in the bottom status bar or right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Using Node / Python local server
```bash
# Using Python 3:
python -m http.server 3000

# Or using npx serve:
npx serve .
```
Then visit `http://localhost:3000` in your web browser.
